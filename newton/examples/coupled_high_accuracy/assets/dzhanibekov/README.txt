Dzhanibekov demonstration asset

The previous demo referred to assets/Nut.usd, which was absent from the project
and the available asset checkouts. Nut.usd in this directory is a new procedural
demonstration wing nut generated by generate_nut.py under the repository license.
It is not a recovered copy of that missing original mesh.

The asset is self-contained: one watertight triangulated mesh at /root/nut, in
meters, with a through hole, two lobes and no external textures or USD layers.
The demo retains its original 30x scale, angular speed and solver settings, and
derives the spin direction from the loaded mesh's principal moments.

Regenerate from the repository root:
  .venv/Scripts/python.exe -B assets/dzhanibekov/generate_nut.py

Use the original mesh if it becomes available:
  .venv/Scripts/python.exe demos/demo/demo_dzhanibekov.py --nut-asset path/to/Nut.usd
