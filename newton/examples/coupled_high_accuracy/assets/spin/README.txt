Spinning gyroscope demonstration asset

The old assets/Gyroscope.usd was absent from the available project and
asset directories. This is a new procedural demonstration flywheel and spindle,
generated by generate_gyroscope.py under the repository license. It is not a
recovered copy of the missing original mesh.

Gyroscope.usd contains one watertight mesh at /root/Gyroscope, in meters, with no
external layers or textures. Balanced flutes make rotation visible. The demo
retains its existing scale, angular speed, zero gravity and enabled collisions.

Regenerate from the repository root:
  .venv/Scripts/python.exe -B assets/spin/generate_gyroscope.py

Use the original mesh if it becomes available:
  .venv/Scripts/python.exe demos/demo/demo_spin.py --gyroscope-asset path/to/Gyroscope.usd
