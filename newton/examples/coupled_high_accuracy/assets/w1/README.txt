Shared W1 demo assets

robot/w1-030: The complete robot asset used by both W1 demos, including URDFs,
collision OBJ meshes, visual GLB/DAE meshes, parallel grippers and D405 cameras.
The 69 files are unchanged copies of the previously loaded local Newton asset.
Its source provenance is newton/examples/mjvbdv2/assets/w1_v030/w1-030 at local
Newton revision 27ffddf6b48c3d79f222abab0919ac7f15eae5f7.

That asset originated in the user-provided
AssembleW1-030/DexforceW1V030/w1-030 directory. The URDF identifies DexForce
Technology Co., Ltd. No additional license is asserted for these robot assets.
The copied version retains the source checkout's repaired finger winding and
normals; geometry, UVs, materials, collision meshes and joint definitions are
unchanged by this migration. GLB textures are embedded. The two collision
sl_scaled.obj files retain references to optional .mtl files absent from the
original package; collision materials are not used by these demos.

courier: Original mailer and shipping-label textures.
pharmacy: Original four-carton print textures and physical mesh archives.
These files were moved from the demo directories without changing their bytes.
Runtime carton geometry is still generated by variant_geometry.py.

fonts/NotoSansCJKsc-Regular.otf: Portable Chinese rendering font from
https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
distributed with its SIL Open Font License in fonts/LICENSE.txt.
It replaces the dependency on C:/Windows/Fonts/msyh.ttc for captions and signs.
Existing carton print images are preserved; regenerating them uses Noto.

manifest.json records SHA256 hashes for every bundled asset. Asset paths are
resolved from the repository location, independently of the working directory.
Generated stance URDFs, SDF caches, trajectories and renders remain in build/.
