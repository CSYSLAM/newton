# W1 购物篮装薯片

W1 左手二指夹爪夹住购物篮提手并把篮子提起约 5 cm，右手夹住薯片袋顶部封口，
把袋子搬到篮子上方放手，袋子落入篮中；随后左手把篮子放回桌面并松开。全程 16 秒。

```bash
# 交互窗口（默认）
.venv/bin/python demos/demo/demo_w1_snack_basket.py
# 无窗口录制 → build/w1-snack-basket（dev1118 求解器约 1 分钟）
.venv/bin/python demos/demo/demo_w1_snack_basket.py --viewer=false
# 检查 + Blender Cycles 渲染 1920x1080、128 采样 + H.264 编码（RTX 5090 约 12 分钟）
.venv/bin/python demos/w1_snack_basket/make_video.py
```

输出：`simulation.usdc`、`trajectory.npz`、`run.json`、`validation.json`、`snack_basket.blend`、
`frames/`、`w1_snack_basket.mp4`。渲染支持断点续渲：已存在的帧会被跳过。
Blender 默认使用 `build/third_party/blender-5.2.0-linux-x64/blender`（由 `~/下载/blender-5.2.0-linux-x64.tar.xz` 解压），
可用 `--blender` 指定。

## 资产

`assets/w1_snack_basket/` 来自 `~/下载/assets`，来源、许可和格式转换见其中的 `README.md`：

- `robot/`：W1 V030 simready 版（修正惯量、重新着色的视觉网格），运动学与 `assets/w1/robot` 一致。
- `basket/`：购物篮 shopping basket001（Extwin，CC BY-NC 4.0）。原模型约为实物 2.8 倍，按 0.36 缩放为
  0.44 × 0.31 × 0.19 m；两侧提手固定在竖起位置。原 120 MB 文本 USD 超过 GitHub 上限，已无损转为 `.usdc`。
- `snack/`：薯片袋 snack004（Extwin，CC BY-NC 4.0）。只使用其印刷贴图；正面、背面在贴图中的区域由原网格 UV 读出。

## 物理模型

- 统一使用 `s3d.NewtonSolver`，8 子步、4 次非线性迭代、50 次线性迭代；机械臂由 IK 轨迹驱动关节目标，
  篮子和薯片袋都只靠接触和摩擦运动，没有任何固定约束。
- 薯片袋：0.15 × 0.22 m，两片膜在周边焊接（侧封 6 mm、顶/底封 15 mm），按充氮枕式袋做成中间厚 85 mm 的
  “靠垫形”：中部大面积全厚，两侧是圆鼓折边，只在顶/底封口前两三厘米迅速收扁（超椭圆截面）。
  膜沿用快递袋的各向异性拉伸参数和焊缝弯曲重建，弯曲刚度取 5e-7（镀铝 BOPP/PET 复合膜比 PE 快递袋硬）。
  封口带保留 4 mm 厚度，只在最外圈焊缝收拢：两片膜若完全重合会落在彼此 1.5 mm 的自碰撞半径内来回推挤。
- 袋内是一块低剪切（800 Pa）、高体积模量（20000 Pa）、低密度（45 kg/m³）的四面体软体，代表“薯片 + 封住的空气”：
  挤压时整体体积基本不变，枕形会向别处鼓起；整袋约 60 g。它与膜之间只有弱的有限长度弹簧和接触。
  渲染时隐藏，只看到膜。
- 录制前在强阻尼下静置 1 秒，让袋子和篮子落稳（机器人此时本来就保持起始姿态），然后时钟归零开始录制。
- 购物篮：0.45 kg 刚体。80 万三角面的线框网格只用于渲染，物理用盒子代理：底板、四面外倾的侧壁和提手顶部的
  两根并拢横杆（左手夹的位置）。
- 左手夹在横杆的重心正上方：二指夹只靠摩擦抵抗绕夹紧轴的力矩，偏离重心会让篮子低头。
  实测提起时篮子最大倾斜约 4°，与手提篮子的自然姿态相近。
- URDF 中每根手指的驱动力上限为 10 N。若像快递袋那样用高刚度、目标远在物体内部的夹紧，两指都会饱和在 10 N，
  夹住的横杆没有侧向回正力而沿夹紧轴滑动（实测 13.8 mm）。左手改用 3300 N/m、目标只比横杆窄 3 mm 的驱动，
  夹紧力相同但处于线性区，侧滑降到约 2.5 mm。
- 右手和快递袋场景一样从袋口外侧收拢夹住封口膜。被夹住的充气袋会沿夹爪方向伸出（前伸约 0.19 m、
  下垂约 0.07 m），所以放手点按袋身位置而不是 TCP 位置安排在篮子靠右半边上方，
  并在篮沿下方约 2 cm 松手：袋子比篮子深 3 cm，落差大时平躺还是竖靠篮壁对初始条件很敏感。

## dev1118 求解器

dev1118 的 PCG 并行调度在本机 Linux（RTX 5090）上验证可用：16 秒仿真 130 s → 64 s。
它改变浮点求和顺序且并行原子加的顺序不固定，同一场景两次运行到 16 秒时个别粒子相差约 8 cm
（接触把末位差异放大）；两次独立运行都通过全部检查。`config.reference_linear_schedule = True`
恢复参考 kernel 顺序，用于与参考 SDK 对照；参考实现本身也用无序原子加，不保证逐次复现。

## 检查

`validate.py` 检查：数值有限；搬运时袋子离开桌面 > 15 cm；篮子被提起 > 3 cm 且悬挂倾斜 < 8°；
最终袋子全部粒子在篮子内壁投影范围内、低于篮沿、在篮底之上；篮子放回桌面（高度差 < 4 mm、倾斜 < 2°）；
内容物四面体没有翻转。包含关系按最终帧的粒子判断，不是连续无穿透证明。

## 渲染

`render.py` 在 Blender 中导入 `simulation.usdc`，把原始购物篮网格挂到仿真篮子刚体上，隐藏碰撞代理和袋内软体。
薯片袋外侧是带薄清漆的印刷膜（原贴图 + 皱褶法线），内侧是镀铝层；灯光为工作室 HDRI + 四盏面光，
AgX Punchy 色调。AgX 会把高饱和红色压成粉色，因此对印刷色做了 1.35 倍饱和度预补偿。
