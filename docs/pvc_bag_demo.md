# PVC 袋侧躺、夹提手、提起与装物

在普通 Newton 窗口运行：

```bash
uv run --extra examples -m newton.examples mjvbd_v2_pvc_bag
```

场景读取 `~/下载/clear_plastic_bag`，无需 W1、Quest、轨迹文件或其他商品资产。
默认袋子宽面侧躺在桌上，袋口朝向前方（世界坐标 -Y），方向与麻绳提手遥操版一致。
两个方块夹爪接近上侧提手的顶部，从提手孔内外夹紧。
夹持点在 3 秒内缓慢垂直抬高 50 cm；袋身的下垂、侧倾和翻起由重力及接触决定，
夹爪不转腕、不横向拖动袋子来强行摆正。
两个质量为 20 g 和 25 g 的动态刚体先停在桌面右侧的小托盘上；
托盘升起，提起后缓慢跟随实际袋口，最后快速向下、向侧方撤离，
使两件物体在重力作用下落进袋子。最后保持夹持，观察承重后的变形。

夹爪在接近和闭合早期跟随提手实际位置，夹紧后固定夹持目标。
只有夹爪、桌子和送物托盘是运动学刚体；袋子和载荷始终自由运动，
通过接触及摩擦传力，不使用固定粒子、抓取吸附或载荷位置重置。

- 空格：暂停/继续。
- 鼠标右键拖拽：拉动袋身或提手。
- 侧栏 `Film opacity`：调整袋身透明度。
- 侧栏 `Reset bag`：复位整个任务，包括两件物体和夹爪。
- 侧栏显示当前阶段：接近、夹紧、提起、送物、撤盘、保持。

单独查看袋子、手动拖拽：

```bash
uv run --extra examples -m newton.examples mjvbd_v2_pvc_bag --no-task --pose upright
uv run --extra examples -m newton.examples mjvbd_v2_pvc_bag --no-task --pose lying
```

`--pose upright` 可从直立姿态开始同样的先提起、再装物任务。
`--paused` 可以先停在初始帧；`--opacity 0.5` 可增加可见度。
`--pvc-assets PATH` 用于更换原资产目录。

物理仍使用从原资产采样的 2,045 粒子、4,040 面网格，保留袋身皱褶及硬空心提手。
普通 demo 的 PVC 袋身参考纸盒的分区材料参数：袋身抗拉伸系数为 `1e5`，袋口为 `2e5`；
面板抗弯系数为 `60`，角部和底部折弯区为 `16`，袋口上沿为 `240`；
对应阻尼为 `2.0`、`0.6`、`4.0`。这些来自纸盒基础材料，不使用虾片包的薄膜参数。
提手抗弯系数为 `300`，U 形保形弹簧只作用于提手自身；根部加固仅连接邻近的袋口网格。
袋身没有贯穿内部的弹簧撑架，也没有从提手跨接到袋身中下部的长距离约束。
全部节点保持动态，保留 PVC 原质量和重力。
默认求解迭代数为 24；提手使用独立的 `--handle-stiffness` 系数，默认 1。
这些是用于预览硬 PVC 手感的近似参数，未经材料实测标定。显示的是半透明物理网格，
而非原 GLB 的高模折射渲染。

可用 `--lift-height 0.5` 调节夹爪上移总距离（米）。

完整任务的无窗口检查（CPU 运行较慢）：

```bash
uv run --extra examples -m newton.examples mjvbd_v2_pvc_bag --viewer null --device cpu --num-frames 420 --test
```

检查包括状态稳定性、提手与夹爪的穿入量、提手的跨度变化，
以及默认抬升距离下袋底是否离桌、两个载荷中心是否位于袋子内部。另有重力自由落体、局部加固范围、提手保形和复位测试；
CPU 测试不覆盖只在 CUDA 上启用的多层求解修正。
