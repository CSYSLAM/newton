# W1 工业分拣场景与机器人姿态

本轮修改限定在 `mjvbd_v2_conveyor_sorting` 示例和它的资产中。

## 场景建模

通过 Blender MCP 在 Blender 5.2 中制作设备，导出实时使用的网格：

- 有圆角、槽口、端盖、内六角螺钉和安装板的铝型材输送机。
- 端部滚筒、轴承座、带散热片的减速电机、回程皮带。
- 钣金控制柜、门缝、锁扣、散热孔、弯曲电缆和操作按钮。
- 显示面板、信号灯、光电传感器，以及带折边和可调脚的工作台。
- 圆角成型托盘、加强筋、提手和标签槽；增加厂房墙板和踢脚保护。

[资产与重建说明](../../../assets/conveyor_station/README.md)包含 Blender
源脚本和 NPZ 格式说明。运行示例无需 Blender，也没有新增运行时依赖。
资产包含 194 个建模对象，导出合并为 15 组材质、38,112 个三角形，文件
381,194 字节。材质区分铝材、不锈钢、喷漆、橡胶和塑料。

原有箱体碰撞面保留并隐藏。托盘内底面仍为 0.685 m，内壁与原来的直壁
碰撞形状对应。提手、圆角等细节是视觉网格；模型并未把这些细节全部加入
碰撞检测。背景和设备装饰件均不参与物品接触。

## 机器人

左臂改为自然下垂、肘部轻弯，手指轻微弯曲，拇指靠近掌侧。
左臂实际关节姿态在生成帧目标时单独指定。保留原来的双臂 IK 参考与初始化，
避免左臂造型调整改变右臂冗余解，影响已经标定的纯接触布料夹持。

头部使用两个实际颈部关节跟踪当前物品的质心，目标用颈部父坐标系计算。
物品切换后平滑转向；完成分拣后继续看最后放置的物品。
角速度限制为 0.70 rad/s，速度指令的加速度限制为 2 rad/s²，并遵守
URDF 的偏航 ±90°、俯仰 -45° 至 25° 限位。限位外的目标不能完全对准。

布料放置后的 0.5 mm/帧微位移过滤沿用上一版，不修改求解器。

## 验证与验收

```bash
uv run --extra examples -m newton.examples mjvbd_v2_conveyor_sorting --num-frames 4200
uv run --extra examples -m newton.examples mjvbd_v2_conveyor_sorting --viewer null --num-frames 4200 --test
uv run --extra dev -m unittest newton.tests.test_mjvbd_v2_conveyor_gaze newton.tests.test_mjvbd_v2_conveyor_settling
```

头部测试覆盖旋转父坐标系、物品切换、完成状态、关节限位、速度限制，以及
不修改其他关节坐标。布料原有测试继续覆盖 CPU/CUDA 微位移过滤与受力运动。

最终版本的 4,200 帧 / 70 秒实时渲染验证通过全部逐帧及最终断言：
