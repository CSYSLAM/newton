# 连续环形传送带

上一版的机架已有工业设备细节，但可见带面仍附着在循环平移的小块上，
回程面和端部滚筒是静态几何。本轮改成完整闭合的视觉皮带，并让带面与
滚筒共享仿真中的皮带累计行程。

## 实现

通过 Blender MCP 修改并导出：

- 4 mm 厚的闭合皮带，包含内外表面、两侧断面、直线承载段、回程段和
  两端半圆包角；上表面高度为 0.7601 m，端部外半径为 0.0521 m。
- 带轴端紧固件的滚筒模板，分别放在 Y = -0.24 m 和 1.76 m。
- 张紧滑座、调节螺杆、锁紧螺母、端部护板和回程护板；电机与驱动轴对齐。
- 调节机构位于机架侧面，检查其包围盒与四个接收托盘均不相交。

带面顶点保持固定，以连续的纵向 UV 输送橡胶纹理，避免端部的可见块跳转。
纹理包含低对比度颗粒、纵向磨痕和一条跨带宽接头，一个纹理周期对应整圈
皮带。轴端以 `travel / radius` 转动，带纹理以 `travel / path_length`
平移。上层朝抓取点运动，下层朝反方向返回，停机时两者同时停止。

原有重叠运动碰撞段及其编号保留，输送接触和机械手夹取方式沿用上一版。
皮带外观是闭合网格，不是可变形橡胶带的动力学求解；张紧机构是视觉建模，
不会改变求解器中的皮带张力。整个场景仍具有实时仿真的画面质感，并非实拍。

[Blender 资产说明](../../../assets/conveyor_station/README.md)包含重建步骤。
静态设备为 39,320 个三角形，皮带为 784 个三角形，滚筒模板为 2,792 个
三角形，后者在两个端部复用。无需安装 Blender 即可运行示例。

完整流程联调发现布料在松手后被带出托盘，失败日志保存为
`trial_release_drag.log`。释放时保持拇指对掌角度，只张开夹持手指，
待机械手退出后再调整对掌角度，避免该关节扫过下垂的布料。

## 验证

```bash
uv run --extra dev -m unittest newton.tests.test_mjvbd_v2_conveyor_belt newton.tests.test_mjvbd_v2_conveyor_gaze newton.tests.test_mjvbd_v2_conveyor_settling
uv run --extra examples -m newton.examples mjvbd_v2_conveyor_sorting --num-frames 4200
```

8 项测试覆盖闭合网格、表面朝向、法线、UV 首尾接缝，CPU/CUDA 上的
运动方向、停机同步、完整纹理周期，以及已有的头部跟随与布料稳定处理。
新增测试还发现并修复了 CPU 渲染辅助数组被默认 CUDA 设备启动内核的问题。

最终版本完成 4,200 帧 / 70 秒带 OpenGL 渲染的分拣验证，全部逐帧检查
和最终断言通过。刚体、软体、布料、充气袋均已分拣；最大抬升分别为
0.234、0.239、0.282、0.232 m。开启原有微位移过滤时，布料最后一秒的
RMS 速度均值为 0 mm/s；充气袋最终体积为初始体积的 0.932 倍。
70 秒、960×720、15 fps 的完整视频通过解码检查，前 4 秒展示传送带近景。
同一最终版本还通过了独立的无窗口 3,600 帧 / 60 秒默认命令验证。

本地完整视频、近景截图、运行日志、最终状态和 Blender 工程位于
`newton/tests/outputs/conveyor_belt_20260910/`，不纳入版本控制。
