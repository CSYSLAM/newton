# W1 conveyor scene refinement — 2026-09-10

本次修改仅涉及传送带分拣 demo、文档、截图和测试，不改变 MJVBDV2 求解器。
场景仍使用 `vbd_kinematic_full`，保留刚体、四面体软块、布料和封闭充气袋的接触求解。

## 最终实现

- 用共用工作台、细支腿、横撑和调平脚替换原来的整板支撑，补充框架槽线、紧固件和材质标识。
- 添加橡胶带面纹理、织物缝线、包装印刷和混凝土地面；调整 OpenGL 灯光、阴影范围与相机。
- 布料盘外尺寸为 40 × 25 cm，软块盘为 19 × 25 cm，其余为 25 × 25 cm。
  托盘间留出间距，碰撞箱和落盘检查使用相同尺寸，避免布料堆叠到相邻托盘边缘。
- 机械手完成释放、退出并通过落盘检查后，才对布料启用整帧微位移过滤。
  每帧仍执行全部 8 个子步与每子步 16 次 VBD 迭代，再比较布料粒子与上一帧的位置。
  默认忽略接料区内小于 0.5 mm 的位移，按接受的位置重建对应速度。
  不改变粒子质量、活动标记或碰撞检测。
- 阈值上限为 `0.25 * |gravity| * frame_dt**2`，避免未受到支撑的布料停止下落。
  `--cloth-displacement-threshold 0` 可关闭过滤。

这是场景级数值阻尼，会抑制阈值以内的微动和慢速滑移；它不是内部能量收敛的证明。
其他 demo 的 surface-fast 配置不受影响。最终版本采用原有的抓放阶段和翻腕动作。

## 验证

设备：RTX 5090 D v2；60 Hz；8 子步；16 次 VBD 迭代；24 次 IK 迭代。
基线为提交 `34a7794` 的场景。以下统计取完整运行 4200 帧的最后 600 帧：

| 指标 | 原场景 | 本次最终场景 |
| --- | ---: | ---: |
| 布料粒子 RMS 速度的时间均值 | 7.982 mm/s | 0 mm/s |
| 帧位置二阶差分 RMS 的时间均值 | 116.132 µm | 0 µm |
| 四种物品完成分拣 | 通过 | 通过 |
| 末态充气袋体积 / 初始体积 | 0.9395 | 0.9396 |

统计针对提交给渲染和下一帧的最终状态，不代表每个内部子步没有运动。
最终场景在第 3508 帧完成分拣；刚体、软块、布料、充气袋的最大抬升分别为
0.238、0.239、0.273、0.228 m。

另外执行并通过：

- 独立默认 3600 帧 CLI 验收，包含有限状态、物体高度、落盘范围、至少 90% 的变形体粒子落入
  托盘，以及布料最后一秒平均 RMS 速度低于 2 mm/s 的断言。
- CPU / CUDA 共 4 项测试，覆盖欧氏距离过滤、接料区外与其他物品不受影响、CUDA graph
  重放后重新受力，以及 8 / 16 / 32 子步下的自由落体。
- 实际布料受力检查：从完成分拣后的状态，对一个粒子向上施加 0.2 N、持续 10 帧，
  最大粒子位移为 12.03 mm；撤去外力后继续运行 120 帧，状态保持有限。
- 修改文件的 pre-commit 检查通过；更新的示例缩略图为直接渲染的 320 × 320 JPEG。

较小的子步阈值、黏性阻尼，以及提前在抓放阶段启用过滤的版本均未保留。
固定末态对照中，0.2 mm/帧只能稳定较轻的堆叠，较差堆叠仍有 12.61 mm/s 的平均 RMS 速度；
0.5 mm/帧使这两种末态的观测后半段均静止。早期落点校正和托盘搬移试验也未保留。
