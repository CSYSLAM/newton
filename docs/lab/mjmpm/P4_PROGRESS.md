## 本轮发现、未修复

- **CPU 上 PIC 碰撞基 + 低空气阻尼发散**：私有与共享实现相同（继承问题）。复现：P1d、`collider_basis="pic"`/`pic27`、`air_drag ≤ 1e-3`、6×6×8 粒弹性块落地，CPU 上第 5–6 步 Gauss–Seidel 发散（10 次迭代内正常、25 次时发散）；CUDA 正常，`S2`/`Q1` 碰撞基正常，默认阻尼 1.0 掩盖该问题。
- **两个碰撞体之间不足两格的间隙**：材料受矛盾约束被高速抛出；P3 暴露、代理掩盖（已写入文档）。
- **大板低阻尼 NaN**：48×48×8 粒、固定网格、`air_drag ≤ 1e-6` 落地时整体 NaN；共享实现更早失败。
- **W1 刚体块夹持中偶发滑转**：限制更粗时间步，根因未定（每指 6–7 个接触点，分布 ±12 mm，转轴主要沿夹爪接近方向）。
- 共享 `implicit_mpm` 的 `gs-soa` 竞争。
